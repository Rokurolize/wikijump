This repository is Rokurolize's fork of [scpwiki/wikijump](https://github.com/scpwiki/wikijump), and it is where Wikijump development happens; the upstream repository is a reference, not a destination for pull requests. The fork develops Wikijump as a Wikidot-compatible emulator: when documentation, tests, or local output disagree with a controlled live observation of Wikidot, the live behavior is canonical.

See [development.md](docs/development.md) for running a local instance, the [Wikijump Glossary](docs/glossary.md) for terminology, and [contributing.md](docs/contributing.md) for contributing to the project.
