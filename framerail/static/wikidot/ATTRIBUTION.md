# Attribution: pinned Wikidot and SCP Wiki stylesheets

The `styles/` directory next to this file holds three third-party stylesheets that Framerail serves so Wikijump pages render like their Wikidot counterparts. They are byte-pins: each filename is content-addressed, and `framerail/tests/wikidot-static-styles.test.ts` records every file's SHA-256 and source URL and verifies them.
