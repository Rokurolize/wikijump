このテーマはそのまま使用することを想定していますが、{{[[include]]}}の後に以下を置くことで色を変えることもできます。
[[div class="blockquote" style="font-family: 'profontwindowsregular', monospace;"]]
:root {
@@  --accentColor: 246,196,3;@@

}

{{@@--accentColor@@}}は主要なアクセントを制御します（既定では黄色）。
{{@@--darkColor@@}}はテーマの背景と暗い陰影を制御します。
RGB形式で希望の色に変更してください。

{{背景に純粋な黒を使わないことをお勧めします。}}
