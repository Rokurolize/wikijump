[[# What]]
+* これは何？
----
これはLt Flopsが作成したテーマです。ダークモードや夜間モードが好ましいあらゆる記事で、広く使えるように作られています。

自分が何をしているか理解している場合にのみ使用してください。

このテーマは**Black Highlighter**、**BASALT**、**Sigma+**と**__互換性がありません__**。
[[/div]]
[[div class="templateInfo"]]
[[collapsible show="クレジット情報" hide="クレジット情報"]]
Flopstyle: DARKは以下のテーマから派生しています。

* [[[theme:flopstyle|]]] [[size 80%]]by [[user Lt Flops]][[/size]]
* [[[theme:penumbra|]]] [[size 80%]]by [[user EstrellaYoshte]][[/size]]

大きなクレジットは、[*https://scp-wiki.wdfiles.com/local--files/theme%3Aflopstyle-dark/alt_logo_bw.png テーマ] [*https://scp-wiki.wdfiles.com/local--files/theme%3Aflopstyle-dark/alt_logo_tyrian.png ロゴ]（[*https://creativecommons.org/licenses/by-sa/3.0/ CC BY-SA 3.0]）を作成した[[user JackalRelated]]にあります。

最後に、テーマ全体をレビューした[[user stormbreath]]と、いくつかの箇所について意見をくれた[[user Croquembouche]]に感謝します。

+++* 2. カスタム変数
++++++* （自分が何をしているか理解している場合にのみ変更してください）
----
変数の変更はすべてCSSモジュール{{[[module CSS]]}}で囲む必要があります。以下に挙げるものは、さらに{{:root}}セレクタでも囲む必要があります。

@@      @@[[span class="bt bb"]]2.1. 色[[/span]] テーマのさまざまな色を好みに応じて変更できます。以下の変数から必要なものだけをコピーし、必要に応じて編集してください。

[[div class="code terminal terminal--dark"]]
**##var(--c-keyword)|[[module##** ##var(--c-builtin)|CSS##**##var(--c-keyword)|]]##**
@@ @@##var(--c-symbol)|:root##{
[[/div]]
[[div class="code terminal terminal--dark"]]
@@   @@##var(--c-comment)|@@/* -- COLORS -- */@@##
@@     @@##var(--c-builtin)|@@--@@accentColor##: ##var(--c-value)|accent_color##;
@@     @@##var(--c-builtin)|@@--@@accentColorLite##: ##var(--c-value)|lighter_accent_color##;
@@     @@##var(--c-builtin)|@@--@@hue##: ##var(--c-value)|hue##;
[!--@@     @@##var(--c-builtin)|@@--@@textColor##: ##var(--c-value)|text_color##;
@@     @@##var(--c-builtin)|@@--@@fgColor##: ##var(--c-value)|foreground_color##;
@@     @@##var(--c-builtin)|@@--@@bgColor##: ##var(--c-value)|background_color##;--]

##var(--c-comment)|/* Defaults (Do not copy):##
##var(--c-comment)|@@ *   @@__accentColor:__## [[span class="col_box" style="background: var(--accentColor); border-color: hsl(325, 88%, 81%)"]]
[[/span]] **Bright Tyrian pink** hsl(325, 80%, 60%)##var(--c-comment)|.##
##var(--c-comment)|@@ *   @@__accentColorLite:__## [[span class="col_box" style="background: var(--accentColorLite); border-color: hsla(325, 88%, 91%, .5)"]]
[[/span]] **Soft Tyrian pink** hsla(325, 80%, 70%, .5)##var(--c-comment)|.##
##var(--c-comment)|@@ *   @@__hue:__## 325deg##var(--c-comment)|.##
##var(--c-comment)|@@**/@@##
[[/div]]

{{accentColor}}は、このページで最も広く使われる変数です。他のすべての変数と比べても、このテーマの利用者が変更しがちなのは通常accentColorだけです。

{{accentColor}}を変更する場合は、他に2つの変数も変更する必要があります。

@@      @@**2.1. (A)** {{accentColorLite}}[[span class="bt bb"]][[size 0%]]:[[/size]][[/span]] これはaccentColorより**高い**明度、かつ**低い**アルファ値にしてください。選んだaccentColorより**少なくとも10%以上**高い明度、アルファ値は**0.5**を推奨します。
@@      @@**2.1. (B)** {{hue}}[[span class="bt bb"]][[size 0%]]:[[/size]][[/span]] これは選んだaccentColorの色相と一致させてください。

好みの色を選ぶには、[*https://hslpicker.com/ HSL Color Picker]を推奨します。**HSL**は人間に扱いやすい色指定方式で、**H**ue（色相）、**S**aturation（彩度）、**L**ightness（明度）を意味します。**A**lpha値（不透明度）を加えたHSL**A**へ拡張できます。

選んだ{{accentColor}}が[*https://www.w3.org/TR/WCAG/#contrast-minimum Web Content Accessibility Guidelines（WCAG）]を満たすか確認するには、[*https://contrast-finder.tanaguru.com/ コントラスト比]を確認してください。[[span class="col_box" style="background: var(--bgColor); border-color: hsl(222, 62%, 63%)"]]
[[/span]] [[span class="wt"]]**hsl(222, 12%, 21%)**[[/span]]を「Background」欄へ、選んだ{{accentColor}}を「Text color」欄へ入力します。WCAGでは、見出し文字に**3以上**のコントラスト比が求められます。
[[/div]]

[[# Sideboxes]]
+++* 4. サイドボックス
----
サイドボックスは組み込みコンポーネントで、2種類あります。

* [[span class="bt bb"]]タイプA[[/span]] {{authorbox}}と[[span class="table1"]]{{sidebox}}[[/span]]
* [[span class="bt bb"]]タイプB[[/span]] {{sidecontainer}}

使い方は種類によって異なります。

* {{authorbox}}と[[span class="table1"]]{{sidebox}}[[/span]]は、モバイル画面を含む{{width=1280px}}以下の画面では表示されません。ページ情報や著者情報の表示に使えます。
* {{sidecontainer}}は、{{width=1280px}}以下の画面ではページ端へ折りたたまれます。その場合、指でタップするかカーソルを重ねると開けます。追加の物語情報の表示に使えます。

これらを設定する前に、この条件を考慮してください。SCP Wiki利用者のかなりの割合はモバイル端末で閲覧しています。
[[/div]]

= ,,//代替テキスト（alt-text）//,,
アクセシビリティ上の理由から、画像には**alt-text**を使うことを強く推奨します。alt-textとアクセシビリティの関係を詳しく知りたい場合は、The Big Hackによる[*https://bighack.org/how-to-write-better-alt-text-descriptions-for-accessibility/ こちらの記事]を推奨します。

要点はこうです。画像を設置しても、視覚障害や全盲の読者など、その画像を見られない読者がいる可能性があります。alt-textは、その画像についてスクリーンリーダーが簡単に解析できる簡潔な説明を提供します。画像ファイルやリンクが利用できなくなった場合にもalt-textは表示されます。

画像にalt-textを設定するには、**Bootstrap画像ボックス**または**[*https://www.wikidot.com/doc-wiki-syntax:images Wiki構文で挿入した画像]**の中へ{{alt}}フィールドを含めるだけです。[[span class="fnnum"]].[[/span]][[span class="fncon"]][[span class="bt bb"]]注意[[/span]] 標準画像ブロックはalt-textをサポートしていません[[/span]]

実演です。

# {{hazard-box-#}}では、数字{{1–5}}が[[[anomaly-classification-system-guide|Anomaly Classification System]]]の色に対応し、さらに紫（{{6}}）と白（{{@@0@@}}）を加えています。色と数字の組み合わせは次の通りです。
 # {{hazard-box-1}} = 緑
 # {{hazard-box-2}} = 青
 # {{hazard-box-3}} = 黄
 # {{hazard-box-4}} = オレンジ
 # {{hazard-box-5}} = 赤
 # {{hazard-box-6}} = 紫
 * {{hazard-box-0}} = 白
# {{hazard-box-image-#}}には、前項と同じ数字を選んでください。
# ここでは、プレースホルダーのリンクを、[[[desk-of-junior-designer-s-yvonne|アートページ]]で紹介されている[[user EstrellaYoshte]]作成のハザード標識のいずれかに置き換えてください。5種類のハザード標識へのリンクをここに列挙しています。とはいえ、このテーマを美しくするうえで画像が非常に重要な役割を果たしているため、ぜひアートページを訪れてupvoteしてください！
