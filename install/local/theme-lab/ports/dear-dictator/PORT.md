# Dear Dictator: SCP-KO → SCP-JP

This is a real port of the Korean branch's [Dear Dictator theme](https://scpko.wikidot.com/theme:dear-dictator), credited on the source page to thd-glasses. The starting wikitext and retained rendered body are in the local `scp-wiki-translation/corpus/ko/pages/theme:dear-dictator` archive. `reference.json` records the acquired page, applied CSS, and asset digests. The foreign page uses custom fonts and imagery, seven media queries, fixed tower layers, a rating warning, pseudo-elements, tables, blockquotes, tabs, and collapsibles.

`candidate.css` is the full applied Korean theme CSS adapted for SCP-JP. The Japanese sample page in `candidate.wikidot.txt` exercises its actual components and includes the original graphic layers. The source Korean fonts are replaced with Japanese font stacks because they rendered Japanese characters incompletely. The source's menu substitutions based on Korean branch `nth-child` positions are removed. The mobile candidate hides the fixed sidebar by default, provides an article menu link, and disables an inherited `#main-content` transition that caused temporary 260 px overflow during viewport changes. The original mobile reference leaves a wide fixed sidebar visible and squeezes its article into a narrow column; the adapted layout keeps the article readable.

The five packaged PNG assets are the images used by the candidate. `build.mjs` writes two self-contained Wikidot sources by inlining those images as `data:` URLs inside a CSS module: a complete Japanese demonstration page and a reusable `-theme.wikidot.txt` include page containing the CSS, menu, and graphic layers. To publish on SCP-JP, save the theme source as `theme:dear-dictator-jp`, then put `[[include theme:dear-dictator-jp]]` at the top of an article. Both generated sources render through the local Deepwell preview without an external asset request. `sidebar-preview.html` is only a Theme Lab fixture: the local authoring site has an empty sidebar, so this supplies representative native `.side-block` markup without saving site navigation. Its class structure was checked against the acquired Korean reference and the local Wikijump SCP-9506 sidebar; its Japanese link labels are test content.

Run the local loop from the repository root after the local dev stack is healthy and the Deepwell RPC token is set:

```sh
node install/local/theme-lab/scripts/theme-lab.mjs serve --socket /tmp/theme-lab-dear-dictator.sock --candidate-url https://scpaiueouiuiuiui.wikijump.localhost:18443/boundary-check --asset-dir install/local/theme-lab/ports/dear-dictator/assets --sidebar-html install/local/theme-lab/ports/dear-dictator/sidebar-preview.html --browser-root framerail --browser-executable /usr/bin/google-chrome
node install/local/theme-lab/scripts/theme-lab.mjs check --socket /tmp/theme-lab-dear-dictator.sock --site-id 6000003 --wikitext install/local/theme-lab/ports/dear-dictator/candidate.wikidot.txt --css install/local/theme-lab/ports/dear-dictator/candidate.css --reference https://scpko.wikidot.com/theme:dear-dictator --offline --selectors install/local/theme-lab/ports/dear-dictator/acceptance-selectors.txt --title '敬愛する独裁者 テーマ' --compact
node install/local/theme-lab/ports/dear-dictator/build.mjs /absolute/output.wikidot.txt
```

The first reference command without `--offline` acquires the foreign page and dependencies into the content-addressed Theme Lab cache. Once that acquisition is complete, all normal checks use `--offline`; the check reports its acquisition count and blocked browser attempts separately. `selectors.txt` retains the exploratory count comparison, while `acceptance-selectors.txt` checks the same shell and component roles for presence when the Japanese sample has fewer repeated examples than the Korean theme page. Four viewport visual pairs are supplementary evidence: the different Korean and Japanese article text and sidebar make pixel RMSE a poor acceptance metric. The actual mobile menu was clicked open and closed at 390 px; the sidebar changed from hidden to 260 px wide and back to hidden.
