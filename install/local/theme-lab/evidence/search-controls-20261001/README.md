# Frozen header search action authority

The per-theme receipts retain 72 anonymous, offline source observations for 24
maintained themes at the current desktop, laptop and tablet viewport sizes.
Every source keeps its query input concealed after focusing the submit button;
clicking the visible button invokes the original Wikidot listener and requests
`/search:site/q/` with the encoded existing value. Navigation is intercepted,
public writes and external requests are zero. The two initially unsettled
Jakstyle clicks remain in `superseded_measurements`; the focused follow-up waits
for the cached fonts and retains the successful native actions.

These are source control observations, not a source visual-identity or full
runtime parity certificate. Reference resource failures and blocked optional
external requests remain in the receipts. The retained objects are the exact
source HTML, CSS and JavaScript needed to inspect this bounded control rule;
images/fonts for a full visual comparison remain owned by the normal reference
cache and package asset gates.

The two `probe-frozen-search-*.mjs` files are byte-exact archived measurement
programs, bound by each receipt. Their task-local paths identify the original
execution; they are not new acquisition commands or a general runtime API.
`source-plan.json` retains their public source input list. `objects/` is keyed
by SHA-256. Completion opens and hashes the relevant theme's receipt and its
retained artifacts. Another theme's observation cannot clear this source gate.
