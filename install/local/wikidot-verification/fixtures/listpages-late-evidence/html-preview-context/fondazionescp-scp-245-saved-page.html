Elemento #: SCP-245

Classe dell'Oggetto: Safe

Procedure Speciali di Contenimento: Le copie di SCP-245 devono essere contenute in computer isolati e connessi tra di loro mediante rete sicura. I suddetti computer sono locati al decimo piano, sezione C del Sito-88. Devono essere eseguite iterazioni individuali di SCP-245-1 regolarmente per assicurare il continuo contenimento.

Qualsiasi cambiamento degno di nota del mondo di gioco di SCP-245-1 deve essere immediatamente notificato all'attuale capo del progetto. In nessuna circostanza la password universale di SCP-245-1 dev'essere comunicata a nessuna delle entità all'interno di SCP-245-1 stesso.

Descrizione: Per maggiori informazioni su SCP-245, scaricare il file di SCP-245-1.

Attenzione: si noti che SCP-245-1 potrà essere eseguito solo su computer che abbiano il Sistema Operativo OSCP o Windows.
