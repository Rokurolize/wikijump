# Deviation: site utility module disposition

- Shim: the raw-source portion of `expand_site_utility_modules` in `deepwell/src/services/render/site_utility_modules.rs`, invoked by `RenderService::expand_secondary_runtime_modules` in `deepwell/src/services/render/runtime_modules.rs`. `resolve_typed_root_site_grid_runtime_modules` is not part of this syntax deviation: it consumes FTML's structured `Module::Runtime` value after parsing.
- Reason it lives in Wikijump: the visible result depends on the request actor and on whether a site-global lookup or mutation is locally available. FTML cannot own those runtime decisions. The remaining scanner recognizes only the frozen closer-free anonymous shapes that FTML does not type yet.
- Why FTML is not yet sufficient: pinned FTML revision `62ebba4efda1f10e82363c23c925061fbe939e49` exposes `Module::Runtime { name, arguments, body }` for an unknown body-bearing module with a next-physical-line body and a closing `[[/module]]`. It does not expose that typed node for the exact closer-free `[[module SiteGrid]]`, `[[module Clone]]`, `[[module ManageSite]]`, or `[[module PetitionAdmin]]` sources in the frozen live evidence. Removing the scanner would therefore replace their observed anonymous output with FTML's generic unknown-module error.
- Evidence: `/mnt/oracle-store/wjlab/issue-scout-20260731/module-own-line-smoke/live-references.jsonl` with SHA-256 `686f9fd383f51b5fe393b5f98b2a7e499010bfb691a39086309170a29982a783`, cases `module-own-line-clone`, `module-own-line-managesite`, `module-own-line-petitionadmin`, and `module-own-line-sitegrid`; public regression seams `deepwell/tests/page.rs::anonymous_page_and_site_utility_modules_match_frozen_safe_states`, `deepwell/tests/page.rs::typed_sitegrid_empty_body_matches_frozen_preview_and_saved_state`, and `deepwell/tests/page.rs::site_utility_modules_preserve_literal_and_reject_unsupported_shapes`.
- FTML backlog decision: keep the closer-free scanner as bounded Wikijump-side debt and do not extend it to body-bearing SiteGrid shapes. Site identity, actor authorization, cross-site policy, and action availability remain Wikijump responsibilities. Empty body-bearing SiteGrid now uses the typed FTML boundary; argumented, populated, case-variant, and foreign runtime nodes remain fail closed.
- Migration condition: FTML exposes typed runtime ownership for the cited closer-free module sources, and Deepwell can remove their raw-source recognition without changing the cited anonymous output or literal-owner boundaries.
